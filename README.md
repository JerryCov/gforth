# gforth

A personal collection of GNU Forth (gforth) practice exercises and
small programs covering math, physics, geometry, and general Forth
programming technique — compound interest, sphere/cylinder area and
volume, degree conversions, the haversine distance formula, the
rocket equation, unit conversions, and more.

Each `.fs` file is self-contained and can be run directly, e.g.:

    gforth ./HeronArea.fs -e bye

Written and reviewed as part of an ongoing personal project revisiting
old, unfinished practice work.
